# Marketplace updates

This project keeps the existing `siyuan-plugins-ai-cli-bridge` repository and manifest name. The display name is SiYuan DeepSeek Harness. Do not create a second marketplace entry merely to rename its display name.

The existing repository is registered in the official [plugins.txt](https://github.com/siyuan-note/bazaar/blob/main/plugins.txt). Build and verify a new version, then publish its `package.zip` through the existing release workflow. Marketplace ingestion and review remain controlled by the marketplace; keeping an ID does not guarantee exemption from its rules.

See the [official plugin sample](https://github.com/siyuan-note/plugin-sample) for current metadata and asset requirements. This repository's previous `plugins.json` submission instructions were obsolete.
